# Floodgate

PicoLimbo can accept Floodgate authentication data forwarded by a proxy running Geyser and Floodgate. Geyser/Floodgate does not need to be installed on PicoLimbo itself.

## Requirements

Your Minecraft proxy must have Geyser and Floodgate configured and must forward Floodgate data to PicoLimbo.

For the Floodgate backend connection, use the same `key.pem` generated by Floodgate on the proxy. Keep this file private because it is used to authenticate Floodgate data.

When using standard Floodgate, enable `send-floodgate-data` in Floodgate on the proxy so the encrypted data is forwarded to PicoLimbo.

## Configuration

Add a `[floodgate]` section to `server.toml`.

### Disabled

Floodgate support is disabled by default. You do not need to configure any other Floodgate options when it is disabled.

:::code-group

```toml [server.toml] {2}
[floodgate]
enabled = false
```

:::

### Enabled

When Floodgate support is enabled, all Floodgate options must be defined.

:::code-group

```toml [server.toml] {2-7}
[floodgate]
enabled = true
key_file = "key.pem"
username_prefix = "."
replace_spaces = true
education = false
education_username_prefix = "+"
education_uuid_legacy = false
```

:::

The `key_file` value points to the Floodgate `key.pem` file. Relative paths are resolved from PicoLimbo's working directory.

### Username prefix

The `username_prefix` is added to normal Bedrock usernames. The default value used by Floodgate is `.`.

:::code-group

```toml [server.toml] {2-3}
[floodgate]
enabled = true
key_file = "key.pem"
username_prefix = "Bedrock_"
```

:::

Prefixes are limited to 16 bytes. PicoLimbo also truncates the resulting Java username to 16 bytes without splitting UTF-8 characters.

Set `replace_spaces = true` to replace spaces with underscores. This is enabled by default.

### Education Edition

EduFloodgate/EduGeyser can send Education Edition authentication data using the same Floodgate payload format.

Enable the `education` option and choose the Education Edition username prefix:

:::code-group

```toml [server.toml] {2-7}
[floodgate]
enabled = true
key_file = "key.pem"
username_prefix = "."
replace_spaces = true
education = true
education_username_prefix = "+"
education_uuid_legacy = false
```

:::

Education Edition players use an Entra OID-based UUID by default. Set `education_uuid_legacy = true` only when the server already has player data created with the legacy EduFloodgate UUID scheme.

### Proxy forwarding

Floodgate data is included in the forwarded hostname alongside the normal proxy forwarding data. PicoLimbo removes only the encrypted Floodgate payload before processing BungeeCord forwarding.

For Velocity Modern Forwarding, configure the proxy to forward Floodgate data before the Velocity authentication query is sent. PicoLimbo keeps the verified Floodgate identity instead of replacing it with the Java proxy identity.

## Testing

A standard Floodgate test can be done with the following setup:

1. Run Geyser and Floodgate on your proxy.
2. Enable Floodgate data forwarding on the proxy.
3. Copy the proxy's `key.pem` to the PicoLimbo server.
4. Enable the `[floodgate]` section in `server.toml`.
5. Connect to the proxy from a Bedrock client.
6. Check that PicoLimbo accepts the connection and uses the configured Bedrock username prefix.

For Education Edition, use EduGeyser/EduFloodgate instead and set `education = true`. The username should use the configured Education Edition prefix.

If authentication fails, check that the key file is the same on the proxy and PicoLimbo and that the proxy is actually sending Floodgate data.
